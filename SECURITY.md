# Security policy

Report suspected vulnerabilities privately using
[GitHub's private vulnerability report form](https://github.com/poisdahl/meal-concierge/security/advisories/new).
Do not post exploit details or sensitive data in a public issue or pull request.

Include the affected commit or version, operating system and agent/store adapter,
expected and observed behavior, potential impact and a minimal synthetic
reproduction. Redact logs and screenshots. Never include passwords, tokens,
cookies, browser profiles, private account identifiers, payment details or
household state/databases. Describe where sensitive data appeared without
copying the data into the report.

Reproduce only in an installation you are authorized to test. Avoid actual
purchases, messages or destructive actions; explain any step that would require
them instead. Coordinate disclosure through the private report.

Security fixes target current `main`; older releases have no guaranteed backport
support. Reports are reviewed on a best-effort basis without a promised response
time. If a credential has been exposed, revoke it through its provider rather
than posting it here.
